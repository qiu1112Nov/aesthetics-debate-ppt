# 页面设计说明｜v0.4内容深化版

本轮保留1920×1080、宣纸白#F3F0E8、深墨绿#343C38、朱砂红#A05C4A、浅灰绿#A4B1A0、页边章节导引、细线与底部结论。按拟用13⅓×7.5英寸PPT换算，48px对应24pt，正文从未通过缩小字号来容纳新增内容。正式PPTX尚未制作，实际对象字号与编辑性仍须后续验收。

设计原则：实质文字承担判断和推理，图解只呈现文字难以说明的方向／路径／空间关系。作品页结合真实全幅与局部，理论页让文字占主导；不是22页统一三栏文本模板。P01、P22保持原版，截图已与修改前逐像素比较。
