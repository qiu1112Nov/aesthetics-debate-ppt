# 22页HTML初稿｜页面设计说明

版本：v0.3-draft。所有页面待审核，确认数0／22。讲稿原文未改写，页面文字为讲稿的展示性摘录／压缩；完整论证仍以 `materials/身即与透视完整讲稿.docx` 为准。本文件不构成正式PPTX演讲备注。

## 统一设计及投影换算

1920×1080、16:9；拟用13⅓×7.5英寸PPT，1920px→960pt，故48px→24pt。所有画布内文字，包括图注、章节导引、SVG标签、来源索引和页码均≥48px。封面标题92px（46pt），正文48–52px，页标题64px（32pt）。浏览器外控制栏属于预览UI，不进入幻灯片；手机只是等比缩放，屏幕物理字高不等于投影字号。正式PPTX仍必须验收实际对象点数。

配色：宣纸白#F3F0E8、深墨绿#343C38、朱砂红#A05C4A、浅灰绿#A4B1A0。正文与宋体标题使用本地Noto CJK SC子集，许可证随包提供；没有对作品施加调色滤镜、AI补绘或变形。文本和图解保持HTML/SVG结构，日后需重建为PowerPoint原生对象，不承诺HTML自动无损转换。

学术信息系统：顶部章节／辩手、细分隔线、原作图注、底部一句结论与页码。封面与结尾用原版主张／结辩句承担结论功能。各页独立设计任务如下，统一网格不等于重复三栏文字模板。
