# P03-v0.6｜信息层级优化

**仅调整排版，全部文字、论证顺序与图示内容保留。P03仍待审核。**

| 角色 | 当前设置 | 阅读作用 |
|---|---|---|
| 总标题 | 84px、700字重 | 全页最大，先识别问题 |
| 导语 | 52px、常规字重、较轻墨色 | 独立成行，与标题及正文分组 |
| 透视／身即 | 68px；副标签48px | 两方主次清楚，图示使用相同边界尺寸 |
| 中轴维度 | 名称52px、600字重；编号48px | 大于正文、轻于两方主标签，承担结构索引 |
| 左右正文 | 48px、400字重、1.3行距 | 原句和自然断句不变，只强调“视点转换”“参与” |
| 我方判断 | 48px小标签／前半句；52px加粗后半句 | 先承认视觉秩序，再明确身即的完整性立场 |

移除主体贯穿横线和维度边框，以轻中轴代替表格网格。结论区与主体间距由16px增至30px，文字按用户给出的两个完整节奏呈现；后半句不再在“将／身体”之间拆开。顶部细线移到导语下方，底部分隔线、统一页脚均保留。

正文未缩小，全部可见文字≥48px（拟用13⅓×7.5英寸PPT时对应24pt）。未改P01/P02确认版，不开始P04，不制作PPTX。理论与素材依据沿用[上一版说明](../v0.5/论证与理论依据.md)及[素材记录](../v0.5/素材来源.md)，本轮未增加论据或更换素材。
